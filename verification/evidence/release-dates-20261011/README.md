# Release-date research — 2026-10-11

All **116** incomplete or approximate active collector items were researched by six agents. The existing date-override owner now contains **61** guarded observations: **57** values/precision flags change, including **53** full dates. **55** items receive no accepted date observation. In total **63** items remain below reliable day precision, including **8** retained/refined month or year observations.

The JSON reports retain exact inspected source excerpts, actual retrieval times, URLs, separated excerpt/response hashes, target identities, attempted routes and remaining gaps. Full response files and full gallery originals stayed in acquisition scratch; their hashes do not claim those original bytes are committed. The retained excerpts are verified by the collector regression gate. Transient press HTML and publisher delivery signatures are omitted.

The registered sources support positive date fields only. The applied dates refer to the matching launch, shipment window or first documented distribution, as stated in each basis. They do not assert every regional wave, individual specimen arrival, finish completeness, Staff allocation or a new printing. German/French/Spanish Jungle evidence is scoped to the native language or country field; it supersedes Bulbapedia’s conflicting blanket non-English February 2000 statement only for those targets.

Date precedence is implemented in `verification/confirmed_release_overrides.json → releaseDates.reviewedItems`. Each observation guards the existing collector item, card release, physical printing and localization. Only named predecessor IDs receive the same date in `analysis_checklist.json`. The collector, website date citation/sorting and source registry consume that same field-scoped record. Shared legacy product summaries are not used to propagate a localized date to sibling products.

Canonical intake, all 116 target outcomes and per-target evidence links are recorded in [completion.json](completion.json). [baseline.json](baseline.json) records the base commit, item IDs and the digest of every non-date/non-source-link item field for the one-time delivery comparison. Permanent regressions compare the date overlay enabled/disabled against the same current inputs, so future authorized card intake can proceed.
