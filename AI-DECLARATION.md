## Notes

- Claude Code and OpenAI Codex have been used as human-directed copilot agents across architecture,
  implementation, testing, documentation, review, issue remediation, and CI/CD configuration.
- The repository owner defines the goals and evidence policy, supplies domain knowledge, reviews
  changes, and retains every legal, licensing, and publication decision.
- AI-produced changes are checked through deterministic regeneration, structural invariants,
  evidence audits, cross-artifact consistency checks, browser tests, and pull-request review.
- Evidence is accepted because it is traceable to a declared source or owner attestation, never
  merely because an AI system proposed it. Unverified claims remain explicit rather than being
  inferred as absent.
- This declaration describes the development process. It does not claim authorship, ownership, or
  AI provenance for third-party Pokémon artwork, card images, trademarks, or source material.
- This is a living declaration and should be updated when the project's AI-assisted workflow
  changes materially.
