# AGENTS.md

The agent instructions for this repository live in **[`CLAUDE.md`](CLAUDE.md)**. Read that file —
it is the canonical copy, and this pointer exists so that agents looking for `AGENTS.md` land on
the same text rather than a second one that drifts.

Two documents back it up and are cited from it:

- [`HANDOVER.md`](HANDOVER.md) — the cold-start entry point: current state, repository layout, and
  the prioritised backlog.
- [`verification/RESUME.md`](verification/RESUME.md) — the verification playbook. Read it before
  adding or changing any confirmation or contradiction.

The one rule to carry in before reading anything: **positive evidence only — an absence is not
evidence.**
